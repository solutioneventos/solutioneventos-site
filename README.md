# Novo site da Solution Eventos

Este pacote contém uma página única, responsiva e pronta para publicação no GitHub Pages.

## Estrutura dos arquivos

- `index.html`: conteúdo principal do site.
- `assets/css/style.css`: aparência e adaptação para celulares.
- `assets/js/script.js`: menu e formulário de orçamento pelo WhatsApp.
- `assets/images/`: imagens, ícone e prévia para compartilhamento.
- `CNAME`: domínio personalizado.
- `robots.txt` e `sitemap.xml`: arquivos para mecanismos de busca.
- `404.html`: redirecionamento para a página principal.

## Como publicar

1. Abra o repositório `solutioneventos/solutioneventos-site`.
2. Apague ou substitua o `index.html` atual.
3. Envie todos os arquivos e pastas deste pacote, preservando a estrutura.
4. Aguarde a publicação do GitHub Pages.

## Fotografias

As imagens `evento-01.png` até `evento-06.png` são artes provisórias. Substitua-as por fotografias reais, mantendo os mesmos nomes, ou altere os nomes no `index.html`.

Tamanhos sugeridos:

- `evento-01`: 1600 × 1000 px
- demais imagens: pelo menos 1000 × 750 px
- formato recomendado: JPG ou WebP, com até 500 KB por imagem

Antes de usar fotos do Instagram ou Facebook, salve os arquivos originais em boa resolução. Evite capturas de tela, textos sobrepostos e imagens enviadas por aplicativos de mensagem, pois perdem qualidade.

## Domínio

O arquivo `CNAME` já contém `solutioneventos.com.br`. O domínio também precisa ser configurado em:

`GitHub → repositório → Settings → Pages → Custom domain`

Depois, os registros DNS devem ser ajustados no provedor do domínio.

## Formulário

O formulário não utiliza servidor e não armazena dados. Ele organiza as respostas e abre o WhatsApp da Solution Eventos.
